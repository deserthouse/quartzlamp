## 第一部分 · 真机+真灯功能终验（按序勾选）

准备：安装 release 包；`adb logcat -s BLE-WRITE` 全程开着（对照定位见第三节）。

- [ ] 1. 冷启动 → 授权蓝牙 → 设备页扫描 → **真灯出现**（不出灯=22 20 过滤失效，回报协议 §5.6）
- [ ] 2. 连接 → 抓帧确认连接即对时帧（`7E0783…`）与 notify 注册；断电重上电 → "重连中…" 4s×3 内恢复
- [ ] 3. 调色页拖色环 → **灯变色且色相位置与屏幕一致**（修复后可见色=发帧值）；亮度松手生效；电源开/关
- [ ] 4. 灯效页选 3-5 个效果 → 灯效切换；**选中"全灯滚动"类效果后**速度上限 70（限幅跟已选效果，
     与正在浏览哪个分类无关）；灵敏度生效
- [ ] 5. 律动·手机麦 → 点麦克风开始聆听 → 对手机说话灯律动；**停止聆听=停止发帧，灯保持最后颜色**
     （协议帧#6 无亮度位——此为如实语义，非缺陷）；Home 键后台后不再发帧
- [ ] 6. 律动·灯载麦 → 切到该源即发 `BC0F0100`（灯端接管）；对灯说话灯律动（帧#8 方向 R0 定案复核）
- [ ] 7. 拾音类型四键 → 灯端风格按 经典=1/柔和=2/动感=3/迪斯科=4 切换（帧#9 复核）
- [ ] 8. 律动·本地音乐 → 播放 → 灯随音乐律动；**静音/低响度段=色相稳定深蓝**（低响度映射，
     非亮度变化——音量→亮度列为 0.3.0 候选，需帧#11 RGB 直发验证）
- [ ] 9. 定时页 → 设 1 分钟后开灯定时 → "已发送·待读回确认" → 灯准时亮；"从灯读取"回填一致、
     标签显示读取目标灯；未设置槽读取后显示"未设置"（关灯槽默认 23:00）
- [ ] 10. （如有第二盏）两盏同连 → 调色双灯同步；断 A 不影响 B（含 A 连接中即断）
- [ ] 11. 关灯再开 App → 状态恢复，无崩溃（`adb logcat -b crash -d` 应空）
