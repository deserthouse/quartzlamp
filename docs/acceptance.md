## 二、真机验收项（需要：真机 + 真灯）

按顺序勾选：

- [ ] 1. 安装 APK（release 包优先），冷启动
- [ ] 2. 授权蓝牙 → 扫描 → 真灯出现在列表（验证 22 20 过滤对真实广播有效）
- [ ] 3. 连接真灯 → 顶栏"已连接"
- [ ] 4. 调色页拖色相 → **灯变色**（第一个端到端硬验收）
- [ ] 5. 亮度滑杆 → 灯亮度变化
- [ ] 6. 电源开关 → 灯开/关
- [ ] 7. 模式页选 3-5 个效果 → 灯效切换；速度/灵敏度生效
- [ ] 8. 麦克风页（手机麦）→ 对手机说话/放音乐 → 灯随声音律动
- [ ] 9. 麦克风页切外麦 → 灯自带麦接管（对灯说话测试）
- [ ] 10. 音乐页播放本地歌曲 → 灯随音乐律动
- [ ] 11. 定时页设 1 分钟后的开灯定时 → 灯准时亮；再读回一致
- [ ] 12. 蓝牙断连重连（关灯再开灯电源）→ App 自动重连（FastBle 3 次/4s）
- [ ] 13. 多灯（如有第二盏）：两盏同时连接 → 调色双灯同步变色

## 四、可选 10 分钟预检（验收不过时定位用）

原厂 App 与本 App 同机对照抓帧：

```bash
# 1. 装原厂 APK，操作同一功能（如拖色相）
adb logcat -c && adb logcat -s BLE-WRITE     # 原厂帧序列
# 2. 装本 App，重复同一操作
adb logcat -c && adb logcat -s BLE-WRITE     # 本 App 帧序列
# 3. 逐字节对比：帧一致而灯行为不同 → 灯端/时序问题；帧不一致 → 协议提取问题（回报 docs/ble_protocol.md）
```
