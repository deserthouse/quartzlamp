## 第一部分 · 真机+真灯功能终验（按序勾选）

准备：安装 release 包；`adb logcat -s BLE-WRITE` 全程开着（对照定位见第四节）。

- [ ] 1. 冷启动 → 授权蓝牙 → 设备页扫描 → **真灯出现**（不出灯=22 20 过滤失效，回报协议 §5.6）
- [ ] 2. 连接 → 抓帧确认连接即对时帧（`7E0783…`，灯无可见变化属正常）
- [ ] 3. 调色页拖色环 → **灯变色**（第一硬验收）；亮度松手生效；电源开/关
- [ ] 4. 灯效页选 3-5 个效果 → 灯效切换；全灯分类下速度上限 70；灵敏度生效
- [ ] 5. 律动·手机麦 → 点麦克风钮开始聆听 → 对手机说话灯律动；停止即暗
- [ ] 6. 律动·灯载麦 → 对灯说话灯律动（帧#8 方向 R0 已定案，此步行为复核）
- [ ] 7. 拾音类型四键 → 灯端风格按 经典=1/柔和=2/动感=3/迪斯科=4 切换（帧#9 复核）
- [ ] 8. 律动·本地音乐 → 播放 → 灯随音乐律动；**静音=灯最暗**（F04 反向验证）
- [ ] 9. 定时页 → 设 1 分钟后开灯定时 → 灯准时亮；"从灯读取"回填一致；未设置槽读取显示"未设置"
- [ ] 10. 意外断连（灯断电再上电）→ 设备页显示"重连中…"，4s×3 内恢复；主动断开不抢连
- [ ] 11. （如有第二盏）两盏同连 → 调色双灯同步；断 A 不影响 B
- [ ] 12. 关灯再开 App → 状态恢复，无崩溃（crash 缓冲应空：`adb logcat -b crash -d`）
