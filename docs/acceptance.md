## 二、真机+真灯验收项（终局，按序勾选）

准备：安装 release 包；开原厂 App 对照（第四节）；`adb logcat -s BLE-WRITE` 全程开着。

- [ ] 1. 冷启动 → 授权蓝牙 → 扫描 → **真灯出现**（22 20 过滤对真实广播有效；不出灯=过滤失效，回报协议 §5.6）
- [ ] 2. 连接 → 灯端 observe：连接后灯收**对时帧**（灯行为无可见变化属正常，抓帧确认 7E0783 即可）
- [ ] 3. 调色页拖色相 → **灯变色**（第一个端到端硬验收）
- [ ] 4. 亮度滑杆松手 → 灯亮度变化
- [ ] 5. 电源开关 → 灯开/关
- [ ] 6. 模式页选 3-5 个效果 → 灯效切换；速度（全灯 tab 上限 70）与灵敏度生效
- [ ] 7. 麦克风页（手机麦）→ 对手机说话 → 灯律动；切"灯载麦"→ 对灯说话 → 灯律动（帧#8 方向 R0 已定案，此步复核）
- [ ] 8. 拾音类型四键 → 灯端风格按 经典=1/柔和=2/动感=3/迪斯科=4 切换（帧#9 R0 已定案，此步复核）
- [ ] 9. 音乐页播放本地歌曲 → 灯随音乐律动（**需真机**：AVD 无 Visualizer 数据，静音应=灯最暗）
- [ ] 10. 定时页：设 1 分钟后开灯定时 → 灯准时亮；"从灯读取"回填一致；未设置的槽读取后显示"未设置"
- [ ] 11. 意外断连（关灯电源再开）→ App 显示"重连中…"，4s×3 内自动恢复；主动断开不抢连
- [ ] 12. （如有第二盏）两盏同连 → 调色双灯同步变色；断 A 不影响 B
- [ ] 13. 定时读回包络核对（协议 §5.7）：抓一次 read 返回的原始字节长度/头尾，回填协议文档

## 四、10 分钟对照预检（验收不过时定位用）

原厂 App 与本 App 同机对照抓帧：

```bash
# 1. 装原厂 APK，操作同一功能（如拖色相）
adb logcat -c && adb logcat -s BLE-WRITE     # 原厂帧序列
# 2. 装本 App，重复同一操作
adb logcat -c && adb logcat -s BLE-WRITE     # 本 App 帧序列（应用内亦有有界帧记录 frameHistory）
# 3. 逐字节对比：帧一致而灯行为不同 → 灯端/时序问题；帧不一致 → 协议提取问题（回报 docs/ble_protocol.md）
```
