## 第一部分 · 真机+真灯功能终验（按序勾选）

准备：安装 release 包（先卸旧版或直接覆盖）；`adb logcat -s BLE-WRITE` 全程开着。

- [ ] 1. 冷启动落在**设备页**；授权蓝牙 → 扫描 → **真灯出现**；连接（顶栏"已连接"，抓帧见对时 `7E0783…`）
- [ ] 2. 设备页电源开关 → 灯开/关（`BC01010155`/`BC01010055`）
- [ ] 3. 设备页亮度滑杆松手 → 灯亮度变化（`BC0506…`）
- [ ] 4. 灯效页·动态 → 选 3-5 个效果 → 灯效切换（`BC0602…`）；选中"全灯滚动"类效果后速度上限 70（`BC08014655`）；灵敏度生效（`BC1201…`）
- [ ] 5. 灯效页·静态 → 色环点选 → **灯变对应颜色且退出灯效**（`BC04…`，可见色=发帧色）；再点"灯效"分段 → 回到灯效（`BC06…`）
- [ ] 6. **设备页调亮度（灯效运行中）→ 灯变亮且灯效不中断**（BC05 全局性硬件复核，D3 语义前提）
- [ ] 7. 设备页拾音卡 → 类型四键（`BC1101…`）与灵敏度（`BC1201…`）→ 对灯说话/放音乐，灯效随灯麦克风律动（若切类型后无反应：可能需显式声源激活，回报——探针项）
- [ ] 8. 定时 → 设 1 分钟后开灯定时 → "已发送·待读回确认" → 灯准时亮；"从灯读取"回填+显示读取目标；未设置槽读取显示"未设置"（关灯槽默认 23:00）
- [ ] 9. 意外断连（灯断电再上电）→ "重连中…" 4s×3 内恢复；主动断开不抢连
- [ ] 10. （如有第二盏）两盏同连 → 指令双灯同步；断 A 不影响 B
- [ ] 11. 杀 App 重开 → 状态恢复无崩溃（`adb logcat -b crash -d` 应空）
- [ ] 12. 预测式返回：系统开"预测性返回动画"后，设置页边缘侧滑有过渡动画且可返回（当前实现=slide+fade 叠层，与 NavHost 定义一致；若你期望缩放窥视视觉，属转场改版决策点，回报即可）

## 第二部分 · 协议仲裁 4 项（发现异常回填 docs/ble_protocol.md §5）

- [ ] A1 周位掩码 bit0 是否对应周一（设"仅周一"，看实际触发日）
- [ ] A2 模式索引与 153 灯效：每分类抽 2 个核对
- [ ] A3 定时读回**响应包络**：抓一次 read 原始字节（长度/头尾）
- [ ] A4 **weekBits=0 写入是否等效取消定时**（设全周不选→应用到灯→观察灯是否不再定时触发）
- [ ] A5 **断电重上电后灯内时钟是否丢失**（若丢：重连 App 后重对时再验设定时生效）
